**First release. This is a pre-release.** The language changes fast. Syntax can change between versions, and old files can stop working. `functor migrate` does not exist yet. Keep your `.fn` files in version control.

## What is in it

- **Symbols from a grammar.** One base, then short operations: `theta.hat`, `sum.circle`, `in.not`, `integral.x2`. Arrow kinds (mono, epi, iso), `set greek(...)`, the Yoneda glyph `yo`.
- **Deform.** `tall`, `wide`, `bend`, `slant`, `taper`, and fences that grow.
- **Structures.** Matrices and grids, fences, aligned chains, commutative diagrams with curved arrows, crossings and 2-cells.
- **Text.** Knuth–Plass line breaks, hyphenation, margin notes that never overlap.
- **Pages.** HTML and a PDF that Functor sets itself. Five styles: Quiet modern (default), Classic, Lecture, Compact, Board. Dark preview.
- **Tools.** `functor check` with hints, `functor trace` (meaning, style, construction, glyph of each symbol), the symbol inspector and the notation check.
- **Reference.** Full language reference and a short cheat sheet for AI models: https://eleadlau-commits.github.io/Functor/reference/
- **Chat extension.** Shows Functor blocks in Claude chats as typeset math.
- **Stress tester.** Random maths and garbage input, 10,000 pages on each change.

## The desktop app is not signed

Your system shows a warning at first start.

- **macOS:** Right-click the app and select **Open**. If macOS still stops it, go to **System Settings › Privacy & Security** and click **Open Anyway**.
- **Windows:** On the SmartScreen window, click **More info**, then **Run anyway**.
- **Linux:** Make the AppImage executable: `chmod +x Functor_0.1.0_amd64.AppImage`.

## Install the Chrome extension

Unzip `functor-extension-v0.1.0.zip`. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select the folder.
