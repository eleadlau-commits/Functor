**Pre-release.** The language changes fast. Syntax can change between versions, and old files can stop working. Keep your `.fn` files in version control.

## What is new since 0.1.0

- **Spell check.** The editor underlines misspelled words in prose and suggests fixes. Math, code and names are not checked.
- **Two-way jumps.** Click in the preview to go to that line of the source. Press `Alt+Enter` or the locate button to show the source line in the preview.
- **Faster live preview.** The preview compiles only the blocks that changed. On a long note, a key press shows in the preview about four times faster.
- **Page breaks.** `set heading(new_page: 1)` starts a new page at each `#` heading. A line with only `===` starts a new page.
- **Empty start.** The desktop app opens with one empty tab, not the sample file. Your open tabs still come back at start. The website keeps the sample.

## The desktop app is not signed

Your system shows a warning at first start.

- **Windows:** On the SmartScreen window, click **More info**, then **Run anyway**.
- **macOS:** Right-click the app and select **Open**. If macOS still stops it, go to **System Settings › Privacy & Security** and click **Open Anyway**.
- **Linux:** Make the AppImage executable: `chmod +x Functor_0.1.1_amd64.AppImage`.

## Install the Chrome extension

Unzip `functor-extension-v0.1.1.zip`. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select the folder.
